# BoysbathroomPoker

A browser-based, **play-money only** Texas Hold'em table for you and your friends.
No real money, no purchases, no withdrawals — chips only ever reset when the host
starts a new game.

## Tech stack

- **Server:** Node.js + Express + Socket.io. All shuffling, dealing, betting
  validation, and showdown logic runs here — clients never see the deck order,
  other players' hole cards, or unrevealed community cards.
- **Database:** SQLite via `better-sqlite3` (file-based, zero setup).
- **Auth:** bcrypt-hashed passwords, cookie-based sessions (`express-session`).
- **Frontend:** Plain HTML/CSS/JS (ES modules), no build step. All graphics —
  cards, chips, the felt table, avatars, icons — are inline SVG generated by
  small JS functions in `public/js/svg/`, and sounds are synthesised with the
  Web Audio API (`public/js/sound.js`).
- **Works offline:** nothing is fetched from the internet. Fonts are served
  from `public/fonts/`, and the Socket.io client comes from the local server,
  so you can play on a laptop with no connection (against bots, or with
  friends on the same Wi-Fi via `http://<your-ip>:3000`).

## Setup

```bash
npm install
cp .env.example .env     # edit SESSION_SECRET if you like
npm run seed              # creates alice / bob / carol (password: poker123)
npm start
```

Open `http://localhost:3000` in a browser. Each player should use their **own
browser (or device)** so sessions don't collide — see "Testing with one
browser" below if you only have one machine handy.

### Environment variables (`.env`)

| Variable | Default | Meaning |
|---|---|---|
| `PORT` | `3000` | HTTP port |
| `SESSION_SECRET` | *(dev value)* | Cookie-signing secret — set a real random string |
| `DB_FILE` | `./data/poker.db` | SQLite file path (auto-created) |
| `SKIP_AUTH` | `false` | **Dev/testing only.** `true` skips login; each browser tab joins as its own `guest_xxxxx` player, so you can play several seats from one browser. Restart the server after changing it. |
| `TURN_SECONDS` | `30` | Turn clock. When it runs out the player auto-checks if they can, otherwise auto-folds. |

## How to start a game

1. Log in (or create an account).
2. On the lobby screen, **Host a new game** — pick small/big blind and your own
   starting chips, then **Create Room**. You get a 5-letter room code.
3. Share the code. Friends use **Join a game**, enter the code and *their own*
   starting chip amount.
4. As host, you can adjust anyone's buy-in in the waiting room before starting,
   remove a player, or press **Add bot** to fill seats with computer players
   (see below). Bots can sit alongside human players at the same table.
5. Click **Start Game**. Hands play automatically, round to round, until
   someone leaves or there's no one left with chips.

## Playing a hand

- **Fold / Check-or-Call / Bet-or-Raise / All-in** live in the betting dock and
  are disabled whenever it isn't your turn or the move is illegal.
- **Your turn** is shown by a gold "Your turn" badge with a countdown, a
  pulsing ring that drains around your avatar, and a "Your turn" tag on your
  seat. Every other player's turn gets the same ring plus a bobbing marker.
- **Double-click (or double-tap) the felt** to check when checking is legal.
- **Drag a chip** from the tray onto the table (or tap it) to add it to your
  bet; a translucent preview shows on the felt. Min / ½ Pot / Pot / Max, the
  slider and the number box set exact amounts.
- **Hold your cards to peek** (left-click, right-click or touch): the view
  leans in, the cards lift and fan apart, then flip face-up. They stay up as
  long as you hold and flip back down when you let go. **P** or the **Peek**
  button gives a timed look instead.
- **Watch the table:** when another player is checking their hand, their
  face-down cards tilt up and settle with a small eye marker beside them. It's
  a tell only — the server never sends anyone else's cards until showdown.
- **At showdown** every player still in the hand turns their cards face-up and
  their seat is labelled with what they made ("Kings full of Sevens", "Flush,
  Ace high"), with the winning five cards highlighted on the board.
- **Sounds** play for dealing, chips, checks, folds, your turn, the last five
  seconds of the clock, and winning. The speaker button in the top bar mutes
  them; the choice is remembered. They're synthesised in the browser, so there
  are no audio files to download.
- **Drop chips to bet:** drag or tap chips from the tray and a button appears
  on the felt — **Confirm call** when they exactly cover the call, otherwise
  **Bet/Raise to** that amount. The ✕ beside it takes the chips back.
- Chips fly from stacks to the betting line, into the pot, and to the winner;
  folded cards are tossed face-down into the muck.
- Keyboard: **F** fold, **C** check/call, **R** bet/raise, **P** peek.
- The **Animations** toggle in the top bar overrides your OS "reduce motion"
  setting (Windows turns that on when "Animation effects" is off).
- Refreshing the page drops you straight back into your table.

## Bots

The host can add computer players from the waiting room. They're deliberately
straightforward (`server/game/bot.js`): each bot scores its hand — pre-flop
from the two hole cards, after the flop from the best made hand — then folds
weak hands, calls medium ones and raises strong ones, comparing the price of a
call against that score, with a little randomness and the occasional bluff so
they aren't perfectly predictable. Premium hands are never folded. Bots take
about a second to act so hands stay readable, they're marked with a robot
badge at the table, and a room closes when the last human leaves.

## Fairness & anti-cheat notes

- Every hand uses exactly one fresh 52-card `Deck` (`server/game/deck.js`),
  shuffled once with Fisher-Yates driven by `crypto.randomBytes` (rejection
  sampling, no modulo bias). The deck is discarded at hand's end — cards are
  never reused or duplicated.
- All betting/turn validation happens in `Table.js` on the server; a socket
  message claiming an illegal action (acting out of turn, checking into a
  bet, raising below the minimum, betting more than you have) is rejected.
- `getPublicState()` strips hole cards for everyone except the viewer
  (revealed only at showdown), so a modified client can't see others' cards.

## Tests

```bash
npm test
```

Covers: deck has exactly 52 unique cards (fresh and shuffled), no card dealt
twice across a full hand, correct card counts per street, exhausted-deck
errors instead of reuse, RNG distribution across repeated shuffles, and hand
evaluation correctness (straight flush, wheel straight, quads vs. full house,
kicker tiebreaks, split-pot ties).

## Testing with one browser

Browser tabs in the same profile share login cookies, so two tabs can't be
two different logged-in players. To try multiplayer solo, either:
- use two different browsers (e.g. Chrome + Firefox), or
- use one normal window + one private/incognito window, or
- open the app on a second device on the same network (`http://<your-ip>:3000`).
